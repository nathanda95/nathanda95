## 🚀 Projets mis en avant

### 🧩 Excel Checker

Application desktop en Python permettant de contrôler des fichiers Excel, notamment dans des contextes de migration de données ou de vérification qualité.

L'outil permet de détecter les colonnes à contrôler, identifier les données obligatoires manquantes, vérifier certains formats et générer un reporting structuré.

**Technologies :** Python, Tkinter, OpenPyXL

[Voir le repository](https://github.com/nathanda95/excel_checker)

---

### 🪄 LEGO Harry Potter 1-4 Archipelago

Projet visant à intégrer **LEGO Harry Potter : Années 1 à 4** dans l'écosystème Archipelago.

Le projet implique de l'analyse mémoire, du suivi de collectibles, de l'identification de maps et du reverse engineering autour du fonctionnement interne du jeu.

[Voir le repository](https://github.com/nathanda95/LHP1_Archipelago)

---

### 🧑‍💼 BCSO-RH

Projet TypeScript lié à la gestion RH et à l'organisation d'une structure.

**Technologies :** TypeScript

[Voir le repository](https://github.com/nathanda95/BCSO-RH)
